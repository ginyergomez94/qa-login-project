# Proyecto QA – Módulo de Login

📌 **Descripción**  
Este proyecto consiste en la validación de un módulo de login usando **Postman** y **SQLite**.  
Se realizaron pruebas de login exitoso, inválido y con usuario inexistente, documentando los resultados en un plan de pruebas, casos de prueba y reportes de bugs.
